# RoverSense

RoverSense to projekt aplikacji internetowej do zbierania i prezentowania pomiarów pochodzących z czujników IoT. Tematyka aplikacji nawiązuje do telemetrii robotów mobilnych oraz łazików badawczych.

Projekt realizowany w ramach przedmiotu **Zaawansowane Aplikacje Internetowe**, semestr zimowy 2026/2027.

## Zakres projektu

Aplikacja obejmuje REST API do odbierania pomiarów przesyłanych przez zarejestrowane czujniki, prezentację serii danych na wykresie i w tabeli oraz panel administratora do zarządzania seriami i czujnikami. Częścią rozwiązania będzie generator danych pomiarowych.
