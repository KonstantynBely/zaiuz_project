# Materiały udostępnione przez prowadzącego

Poniższe pliki pochodzą z materiałów przedmiotu **Zaawansowane Aplikacje Internetowe (26Z)**, udostępnionych przez prowadzącego:

- `zai-api-26z.yaml` — specyfikacja REST API w formacie OpenAPI 3.1.
- `zai-tests.mjs` — skrypt testujący zgodność aplikacji z wymaganiami projektu.

Pliki zamieszczono bez zmian.
